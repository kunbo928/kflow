# kflow

kflow is a **Skill Pack** — a collection of AgentSkills.io-compatible skills that
can be installed into AI coding tools and read by agents at task time. It helps
orchestrate the software lifecycle with humans in the loop.

## What kflow provides

- **26 skills** covering requirements, architecture, features, bugs, refactoring,
  audits, knowledge capture, and more
- **Workflow CLI** for installing, syncing, and inspecting kflow assets in your
  project
- **Platform integrations** for Codex, Cursor, Claude Code, and OpenCode
- **Project templates** — platform-neutral Markdown documents for every phase of
  the lifecycle

## How it works

1. **Onboard** — run `npx kflow@latest init` in your project
2. **Use workflows** — invoke `/k-flow` inside your Agent Runtime
3. **Keep in sync** — `kflow sync` refreshes your project assets
