# k-author

写给 Agent 读的文档：根 `AGENTS.md`、`.kflow/project-map/`、产品 `SKILL.md` 与 reference。`k-knowledge` 与 `k-onboard` 点名本 Skill。不新建 Work 类型。手法见 [`references/writing.md`](references/writing.md)。

每份 Markdown ≤300 行。步骤写完成条件；参考材料按需加载。指针写清触发分支，不复述环境里一查即得的命令或目录。禁止靠否定句教行为：先写要做什么。
