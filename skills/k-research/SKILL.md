# k-research

先读项目地图。独立调研通过 `kflow work` 使用 `works/research-{slug}/`；服务于既有 Work 的调研留在该 owner 内并由 Spec 链接。

Spec Clear 要求明确一个可回答问题、范围、证据标准、服务的决策和停止条件。优先使用源码、测试、规范和官方文档；重要主张必须追溯到事实 owner，区分事实与推断，并按真正影响决策的维度比较方案。

结果包含证据、结论、适用边界、未知项和建议。调研不授予实现、外部写入、购买或发布权限。只同步经过核实的稳定事实，把结论和来源写入 `spec.md`，并报告 `work.md` 是否具备删除条件，由用户决定。
